# Prior-art and novelty audit — 2026-11-26

## Question and closest prior source

B. Mehrdad, *Graphs versus loopless digraphs with a given degree sequence, and convergence of uniformly random graphs at every density*, arXiv:2611.02191v1 (1 Nov 2026), https://arxiv.org/abs/2611.02191 . The indexed full-text mirror https://arxiv.cnoctave.top/pdf/2611.02191 was inspected, especially Conjecture 1.1, Theorems 1.2–1.4, 4.2, 6.1–6.2, Lemmas 9.1–9.6, Theorem 9.4, Corollary 9.9, Corollary 10.4 and the closing open-problems discussion. Its stated general comparison includes an additional log n in the exponent. It supplies the same Euler-colouring framework and compatible odd-component switch. Its local transition-merging argument and global inverse endpoint count are not used to bound multiplicities here. The new argument uses one Euler tour per component and a local code whose cost is bounded by the number of vertices of each output component. We derive the explicit degree-sensitive upper bound D <= 4^n P(d) G^2 and C=1 in the original conjecture. The stronger polynomial-loss proposal in the prior source is not solved.
